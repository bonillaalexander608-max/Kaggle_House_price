# Original material

The R/Rmd files are byte-for-byte copies of the supplied sources; filenames are standardized for links. `original_render.log` is the supplied rendering diagnostic. `analysis/House_Prices.Rmd` is the same notebook with only portable input paths, CSS spelling corrections and an explicit scope note. Original model code, feature engineering and interval construction are retained.

Run the notebook as the principal analysis; the exploratory .R scripts are separate session-dependent variants, not four stages of a new pipeline. The saved HTML is available for reading without rerunning those experiments. Saved `.RData` and console history are session backups, not required public analysis files; they are not published or claimed as verified model outputs.
