# Competition inputs

Download `train.csv` and `test.csv` from [Kaggle House Prices](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data) and place them in this folder. A Kaggle account and acceptance of the competition rules may be required. Use comma-separated original CSVs, not a semicolon-converted spreadsheet export.

Expected shapes: train 1460 × 81, test 1459 × 80. The test file has no SalePrice labels. Competition files are not redistributed here; obtain them directly under the source terms. The supplied local attachments were checked for these shapes and unique IDs.

The project concerns Ames, Iowa, USA. It does not validate prices in Nicaragua.
