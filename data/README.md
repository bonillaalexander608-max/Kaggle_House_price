# Ames House Prices inputs

`raw/train.csv` and `raw/test.csv` preserve the supplied comma-separated files: 1460 × 81 and 1459 × 80. `data_description.txt` is the supplied variable dictionary. The original scripts used semicolon-delimited local copies; the portable notebook reads the attached comma-separated version.

Source: [Kaggle House Prices — Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques). Dataset ownership and reuse conditions remain those of the source. SalePrice is observed only in train. The competition test file cannot supply local accuracy or coverage without its true labels.
